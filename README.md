## 买 VPS 前，先定三件事

### 用途决定配置，内存通常是瓶颈

内存是最容易算错的一项。按常见用途对照：

- 静态网站：512MB 就能跑，建议 1GB
- WordPress、小型 API：1GB 起步，2GB 更从容
- Docker 两三个容器、n8n 之类的自动化流程：2GB 起，4GB 推荐
- 数据库、游戏服务器：4GB 起

硬盘方面，NVMe 比 SATA SSD 快 3–5 倍，但挂博客、跑测试环境时这点差距基本感知不到，不必为用不上的速度多付钱。月流量 1–2TB 是目前的主流配置，个人建站一般用不满。

### 机房位置跟着用户走，而不是跟着你走

选机房的原则只有一条：离你的用户近，离你自己远近无所谓。面向亚太用户，洛杉矶、新加坡、东京都是常见选择。从大陆访问的角度看，排序大致是：国内机房最好，其次是香港、台湾等周边地区，然后是日本、韩国、新加坡，再次是美国等更远的机房。

线路方面，国内测评站给出的排序是 CN2 GIA > AS9929 > AS4837 > CN2 GT，实际体验还要结合本地网络。这正是后面单独讲 CN2 GIA 的原因——同一配置的服务器，线路不同，晚上的表现可能是两个世界。

## 常见问题

### VPS 购买一般要花多少钱？

按 2026 年的行情，1 核 1GB 配置的合理价格是每月 $4–6，2 核 2GB 是 $8–12；预算档的商家（RackNerd、Hostinger）入门款低到每月 $1.99 左右。搬瓦工 20G 款折合 $4.17/月，处于合理区间下沿。

### 1GB 内存够用吗？

够不够取决于用途：静态网站和 WordPress 够用，Docker 多容器、自动化流程建议 2GB 起，数据库和游戏服务器 4GB 起。拿不准就先从 1GB 开始，撑不住再换 40G 款的 2GB。

### VPS、虚拟主机、独立服务器怎么选？

虚拟主机每月 $3–10、没有完整控制权，适合纯展示小站；VPS 每月 $5–50、有完整 root 权限，适合大多数项目；独立服务器每月 $50 起步，留给大流量业务。对多数人来说 VPS 是控制力和成本之间的平衡点。
